Teoria dos Grupos

O que é

um Grupo?

Um grupo é uma estrutura algébrica formada por um conjunto não-vazio G munido de uma operação básica ○ que satisfaz quatro axiomas fundamentais. Esses axiomas capturam a essência da simetria matemática.

(G, ○)

Os quatro axiomas
G1 FECHAMENTO
∀ a, b ∈ G : a ○ b ∈ G

Para quaisquer dois elementos do conjunto, o resultado da operação também pertence ao conjunto. O conjunto é fechado sob a operação definida.

G2 ASSOCIATIVIDADE
∀ a, b, c ∈ G : (a ○ b) ○ c = a ○ (b ○ c)

O agrupamento das operações não altera o resultado. Pode-se reordenar os parênteses livremente sem mudar o produto final.

G3 ELEMENTO NEUTRO
∃ e ∈ G : ∀ a ∈ G, a ○ e = e ○ a = a

Existe um elemento especial que, ao operar com qualquer elemento, retorna o próprio elemento inalterado. É único quando existe.

G4 INVERSATIBILIDADE
∀ a ∈ G, ∃ a⁻¹ ∈ G : a ○ a⁻¹ = a⁻¹ ○ a = e

Cada elemento possui um inverso no conjunto tal que a operação entre eles resulta no elemento neutro. Todo elemento é reversível.

OBSERVAÇÃO

Note que a comutatividade (a ○ b = b ○ a) não é exigida. Quando ela também vale, o grupo é chamado de grupo abeliano ou grupo comutativo. O verificador abaixo checa apenas os quatro axiomas fundamentais, indicando também se o grupo encontrado é abeliano.

O que é um Grupo Cíclico?

Um grupo é cíclico se existe um único elemento que o gera inteiro

Um grupo G é chamado de cíclico quando existe algum elemento g ∈ G — chamado de gerador — cujas potências sucessivas produzem todos os elementos do grupo:

G = { g⁰, g¹, g², …, gⁿ⁻¹ }

Equivalentemente, G é cíclico se e somente se existe um elemento de ordem |G| — isto é, um elemento cuja ordem é igual ao número de elementos do grupo. Todo grupo cíclico finito de ordem n é isomorfo a ℤₙ.

G = ⟨g⟩

Ordem de um elemento

ord(a) = min{ n ∈ ℤ⁺ : aⁿ = e }

A ordem de um elemento a ∈ G é o menor inteiro positivo n tal que aplicar a operação do grupo n vezes consecutivas sobre a retorna o elemento neutro e.

Formalmente, escrevemos aⁿ = a ○ a ○ … ○ a (n fatores). O elemento neutro sempre tem ordem 1, pois e¹ = e. Todo elemento de um grupo finito possui ordem finita, e pelo Teorema de Lagrange, a ordem de cada elemento divide a ordem do grupo |G|.
